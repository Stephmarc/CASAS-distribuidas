# S06 · Comunicación resiliente

Reserva consulta propiedad con Feign (`casa-propiedad-ms`), timeout, dos intentos de transporte como máximo para lecturas y Circuit Breaker. La consulta de detalle devuelve `degradado=true` y los datos locales si la dependencia cae. Crear una reserva exige una validación real y devuelve 503 si no puede realizarla.

## Prueba

Crear una reserva, detener **solo** `propiedad-ms`, consultar su detalle varias veces y revisar el circuito. Reiniciar propiedad y comprobar recuperación. Usar `scripts/test-resilience.ps1`; conserva la referencia de reserva y recupera el proceso en `finally`.

Un 404 de negocio no equivale a indisponibilidad; un 401/403 remoto conserva su significado. El fallback no fabrica disponibilidad. Ver `PropiedadIntegrationService` y `ConsultasRemotas`.
