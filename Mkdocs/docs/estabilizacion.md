# Estabilización del backend

La revisión refuerza la intención persistente de pago, conciliación, compensaciones, orden de mensajes, agenda, pertenencia y operación del proyecto. Conserva los nueve servicios y el negocio inmobiliario.

La explicación actual está en docs/CAMBIOS_ESTABILIDAD.md en la raíz. La actualización y los resultados se describen en docs/ACTUALIZAR_SIN_BORRAR_DATOS.md y docs/VERIFICACION.md. La compilación final pasó 78 pruebas con Java 21. Los tests HTTP ampliados se ejecutan mediante scripts/test-stability.ps1.
