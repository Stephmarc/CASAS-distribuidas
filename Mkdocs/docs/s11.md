# S11 · Cliente Angular

La interfaz adapta el prototipo de CASAS: crema, verde oscuro, tipografía editorial, ilustración propia y tarjetas de inmuebles. El catálogo permite filtrar por ubicación, operación, presupuesto y disponibilidad.

## Recorridos

- Cliente: registro con DNI → detalle → pregunta de visita previa (con fecha si la desea) → reserva de 24 horas → pago con Yape, Plin o transferencia subiendo la captura → seguimiento con barra de progreso (Reserva, Pago, Verificación, Contrato, Listo) → aceptar el contrato; favoritos, visitas y notificaciones en «Mi espacio».
- Agente: panel con tareas pendientes, sus inmuebles, visitas (confirmar, reprogramar), revisión de pagos con la captura (aprobar, pedir otra, rechazar), contratos (enviar y activar) y reservas a nombre de un cliente.
- Administrador: lo anterior más resumen con indicadores, todos los inmuebles, operaciones (cancelar), alta y baja de agentes, activar o desactivar clientes, exportación CSV y pantalla de sistema (Grafana, Eureka, Keycloak, Kafka UI).

Angular usa `keycloak-js` con PKCE; no almacena tokens en localStorage ni sessionStorage. Las llamadas de negocio utilizan únicamente `http://localhost:28080/api/v1`. La autenticación se comunica con Keycloak, como corresponde al protocolo OIDC.

Las rutas protegidas vuelven al inicio si falta sesión. La ruta de gestión exige rol real del token. Esta protección de interfaz acompaña la validación del servidor: ocultar un botón no concede ni revoca un permiso de API.

Las órdenes se actualizan cada siete segundos sin recargar la página. Si la reserva se guardó y falló la creación de orden, «Mi espacio» muestra el aviso «Continuar mi reserva», que reutiliza la misma clave de idempotencia. Los errores y estados vacíos son visibles; no se sustituyen por datos inventados.

## Servicio externo real

El detalle de un inmueble consulta la ciudad por `propiedad-ms` usando la API real de geocodificación de Open-Meteo / GeoNames. Angular solicita esa información únicamente por Gateway y ofrece un enlace al mapa de la ciudad. La consulta tiene timeout y caché de 30 minutos; si falla, la reserva sigue disponible. Las coordenadas son una referencia urbana, no el domicilio del inmueble. La integración se comprobó con Juliaca (Puno, Perú). El adaptador de Mercado Pago conserva su validación externa pendiente.
