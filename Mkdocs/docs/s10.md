# S10 · Observabilidad

El Compose incluye Prometheus, Loki, Alloy y Grafana. El tablero **CASAS · Operación distribuida** se provisiona automáticamente.

| Consulta | Finalidad |
|---|---|
| `up{job="casas"}` | Servicios alcanzables por el recolector |
| Tasa HTTP por aplicación | Tráfico y distribución |
| Tasa 5xx | Fallos del servidor |
| Histograma p95 | Latencia |
| Memoria heap | Presión sobre la JVM |
| Logs por trace | Diagnóstico de una operación |

`/actuator/health/liveness` indica vida del proceso. `readiness` incluye la base de datos; un proceso vivo puede no estar listo. Los endpoints de métricas son públicos solo en el laboratorio local; otros endpoints Actuator requieren ADMIN.

Los archivos `.run/logs/casa-*.log` se montan en Alloy y se envían a Loki. Filtrar el tablero por un `traceId` recibido del Gateway para comparar orden, reserva, propiedad y los eventos correspondientes. La disponibilidad del recolector no demuestra por sí sola que un flujo de negocio terminó.

Grafana: `http://localhost:23000`, usuario `admin`, clave de desarrollo `casas-demo-local`. Puede cambiarse con `GRAFANA_ADMIN_PASSWORD`.
