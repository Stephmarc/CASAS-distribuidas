# Catálogo de demostración

Nueve inmuebles ficticios para recorrer compra, alquiler, visitas y reservas. Precios, domicilios y características son datos de ejemplo. No representan anuncios reales. Las fotografías ilustrativas se sirven desde Unsplash y no identifican esos inmuebles.

Ejecutar `scripts/seed-demo.ps1` con CASAS iniciado. El script reutiliza los agentes de laboratorio y evita duplicar títulos existentes. No modifica propiedades previamente reservadas ni elimina registros.
